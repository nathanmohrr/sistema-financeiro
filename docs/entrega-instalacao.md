# Sistema Financeiro — Guia de Entrega e Instalação

Este guia ajuda a instalar e usar o aplicativo no Windows.

## Requisitos
- Windows 10 ou superior (64 ou 32 bits)
- Internet para login e sincronização com a nuvem (Firebase)

## Instalação
1) Execute o arquivo: "Sistema Financeiro Setup X.Y.Z.exe" (fornecido pelo suporte).
2) Se o SmartScreen avisar:
   - Clique em "Mais informações" > "Executar mesmo assim".
3) Conclua o assistente. O aplicativo aparece no Menu Iniciar como "Sistema Financeiro".

## Primeiro acesso
- Abra o app e crie uma conta ou faça login.
- Os dados são salvos na nuvem; cada conta vê apenas seus próprios dados.

## Atualizações
- Quando houver nova versão, você pode:
  - Reinstalar com um novo instalador (método padrão), ou
  - Se habilitado, usar o menu Ajuda > "Verificar atualizações".

## Desinstalação
- Configurações do Windows > Aplicativos > "Sistema Financeiro" > Desinstalar.

## Privacidade e segurança
- O app usa Firebase (Google) para autenticação e armazenamento.
- Não compartilhe sua senha. Use "Esqueci a senha" para recuperar acesso.

## Suporte
- Entre em contato com o fornecedor do sistema.
